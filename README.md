# Amiguito Pro · byGui

Bichinho virtual **premium e gratuito** pra crianças (~3–4 anos, mentes curiosas). Cuidar, brincar, aprender inglês, yoga suave e roteiros com estrelas.

Site estático (HTML/CSS/JS). Sem conta, sem anúncios, sem pagamento, sem chat aberto. Tudo no navegador (`localStorage`).

🌐 **https://guilhermeromio-netto-prog.github.io/amiguito-virtual/**

## Personagens

| Amiguito | Quem é |
|----------|--------|
| **Luna** | Gatinha curiosa |
| **Pipoca** | Cachorrinho brincalhão |
| **Fogo** | Dragãozinho gentil |

Dá pra **dar um nome** (até 12 letras) na tela inicial.

## O que tem no Pro

1. **Casa** — alimentar, brincar, descansar, carinho (barras + quarto fofo + partículas)
2. **Brincar** — lanche, bolhas/estrelas, esconde-esconde, memória, dança do tap, fantasia
3. **Roteiros** — Exploradora das Cores, Números Ninjas, Inglês com Amiguito, Yoga Suave, Desafio do Dia
4. **Ensinar & Inglês** — cores, números, palavras, gentileza + Hello/animals/body/numbers (dicas PT/EN)
5. **Yoga suave** — 8 poses de animal com timer e respiração (brincadeira, não é orientação médica)
6. **Missões + troféus + sequência de dias** (streak gentil)

## Dica pra adultos (jogar junto)

- Sessões de **5–10 minutos** funcionam melhor nessa idade.
- Celebre o esforço: “você tentou de novo!” vale mais que só o acerto.
- No inglês, digam as palavras **em voz alta** juntos (Hello! Please! Thank you!).
- Yoga: acompanhe a pose, sem forçar; se houver desconforto, parem com carinho.
- O progresso fica **só neste aparelho** — não apague os dados do navegador se quiser manter.
